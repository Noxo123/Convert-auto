# Convert Auto

Convertisseur web rapide et automatique, inspiré d'Excel.

## Fonctionnalités
- Glisser-déposer de fichiers
- Détection automatique du format
- Aperçu en tableau éditable
- CSV / TSV / XLS / XLSX / JSON / XML / TXT / HTML
- Export CSV, Excel, JSON, XML, TXT ou HTML
- Conversion rapide d'unités (longueur, poids, température, données)
- Traitement des fichiers côté navigateur pour les conversions supportées
- Interface responsive et sans installation

## Utilisation
Ouvre `index.html` dans un navigateur ou publie le dépôt avec GitHub Pages.

## Suite prévue
- PDF ↔ images / texte
- DOCX / ODT
- images (JPG, PNG, WebP, SVG)
- audio / vidéo
- conversions de devises avec taux en direct
- historique des conversions
- traitement de plusieurs fichiers et téléchargement ZIP
- détection plus avancée du contenu
